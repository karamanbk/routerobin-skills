# RouteRobin agent skills

Agent skills for [RouteRobin](https://routerobin.com/?utm_source=agent-skill&utm_medium=skill&utm_campaign=sf-agent-routerobin-embed): free scheduling, round-robin and lead routing for B2B sales teams. They work with Claude Code, Codex, Cursor and any agent that reads `SKILL.md`.

## routerobin-embed

Adds a RouteRobin booking calendar or lead routing form inline to a website (HTML, Next.js, React, Astro, Webflow, Framer), and wires up the booking event and the thank-you redirect.

```bash
npx skills add karamanbk/routerobin-skills
```

You need a free RouteRobin account and the id of an event type or routing form (RouteRobin, then Event Types or Routing, then Embed). No API key is needed.

Try asking your agent:

- "Add a book-a-demo calendar to the pricing page. My RouteRobin event type id is …"
- "Put my RouteRobin routing form on /contact and send GA4 an event when someone books."
- "Our Framer site needs the RouteRobin calendar inline, in our brand colors."
